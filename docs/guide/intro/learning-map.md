# 数字 IC 学习地图

> 占位文档：后续会补充更完整的学习路径与推荐资料。

一条常见的数字 IC 学习主线可以粗略分成：

1. **数字基础**：组合/时序逻辑、FSM、Verilog/SystemVerilog 基础
2. **前端设计**：RTL 编码规范、仿真、覆盖率、综合约束意识
3. **后端实现**：综合、布局布线、时序收敛、功耗与签核概念
4. **工艺与库**：标准单元库、工艺节点差异、PVT 角

建议先建立「概念地图」，再按项目需要深入某一段。本站知识库会按这个骨架逐步填充。
